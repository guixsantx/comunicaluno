🎓 ComunicaAluno: Sistema Centralizado de Comunicação Acadêmica
📝 Descrição
O AcademicBridge é uma plataforma desenvolvida para resolver o abismo de comunicação entre o corpo discente, docentes e a coordenação acadêmica. O projeto nasce da necessidade de centralizar avisos, solicitações e feedbacks em um ambiente seguro, auditável e exclusivo para a comunidade universitária, eliminando a dispersão de informações em canais informais.

🚀 Proposta de Valor
Diferente de ferramentas de mensagens genéricas, o portal foca no fluxo de trabalho acadêmico, permitindo que solicitações tenham status de acompanhamento (ex: "Pendente", "Em análise", "Resolvido"), garantindo que nenhuma dúvida ou problema do aluno fique sem resposta.

🛠️ Arquitetura e Funcionalidades
Autenticação Restrita: Sistema de login robusto para garantir que apenas usuários com vínculo institucional (Alunos e Professores) acessem a plataforma.

Gestão de Perfis (RBAC):

Alunos: Abertura de chamados, visualização de murais da turma e contato direto com coordenação.

Professores: Centralização de avisos importantes e gestão de dúvidas por disciplina.

Administradores (Devs/Staff): Gerenciamento de usuários e manutenção da integridade do sistema.

Mural de Avisos Inteligente: Notificações filtradas por relevância e urgência.

💻 Stack Técnica (Sugestão para o seu perfil)
Frontend: React / Next.js (para uma interface rápida e responsiva).

Backend: Node.js (TypeScript) ou Java (considerando sua experiência com sistemas legados).

Banco de Dados: PostgreSQL (para garantir a consistência dos dados de usuários).

Autenticação: JWT (JSON Web Tokens) com suporte a contextos de segurança.
